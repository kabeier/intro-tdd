1 · Export it, then require it

Files: factorial.js and runner.js. Type each block yourself (copy only if you fall behind), save, then run.

Step 1 · factorial.js

function factorial(num) {
  let product = 1;

  for (let i = num; i > 0; i--) {
    product = product * i;
  }

  return product;
}

Bonus · run Jest in a container

    
First a .dockerignore, so your laptop's node_modules isn't copied over the container's:

    
node_modules

    
Then the lesson's Dockerfile, saved as Dockerfile:

    
FROM node:18-alpine

WORKDIR /app

COPY package*.json ./

RUN npm install

RUN npm install --save-dev jest

COPY . .

CMD ["npm", "test"]

    
docker build -t jest-tests .
docker run --rm jest-tests
echo $?

    
Same PASS output as on your laptop, and exit code 0. That exit code is what a CI pipeline checks before it lets anyone merge.
