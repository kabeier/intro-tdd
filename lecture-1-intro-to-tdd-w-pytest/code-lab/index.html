Before you start

  1. Install pytest and check it: 
    pip install pytest
pytest --version
    pip not found? Use pip3, or python3 -m pip install pytest (then run tests with python3 -m pytest).
  2. A folder for today, opened in VS Code: 
    mkdir tdd-pytest
cd tdd-pytest
code .
  3. Make example.py as an empty file for now. Save (Ctrl+S / Cmd+S) before every run.

Bonus · run the tests in a container

The lesson's Dockerfile. Save it as Dockerfile in tdd-pytest/:

FROM python:3.11-slim

WORKDIR /app

COPY . .

RUN pip install --no-cache-dir pytest

CMD ["pytest"]
docker build -t pytest-tests .
docker run --rm pytest-tests
echo $?

RUN happens while building (installs pytest). CMD runs when the container starts: the whole suite, once. You should see 8 passed and exit code 0. Then try this: in example.py change + to -, save, and run without building: still 8 passed (the image has the old copy). Build again (COPY happens at build time), run: 1 failed, 7 passed, exit code 1. Change it back, build, run.

Check: you're done when…

  1. You saw test_example.py fail (ImportError) before it passed
  2. pytest with no file name runs all your test files, and they pass (after you remove "jam")
  3. You can say what ., F and E mean, and what exit codes 0, 1, 2 and 5 mean
