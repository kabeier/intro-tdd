Homework Part I: pytest

In this order, top to bottom (each is a little harder): (1) Roman Numerals (Python), (2) Linear Search (Python). Then 50 steps of your current FreeCodeCamp certification.

1 · Get each assignment

  1. Open the assignment on GitHub and click Fork → Create fork.
  2. Clone your fork and open it (Roman Numerals as the example): 
    git clone https://github.com/YOUR-USERNAME/algo-roman-numeral-py.git
cd algo-roman-numeral-py
code .
    VS Code may offer to Reopen in Container. You can skip it.
  3. pytest installed? pytest --version. If not: pip install pytest (or pip3).

2 · Red first, then green

  1. Before writing code, run the tests and watch them fail:
    AssignmentYour codeRun
    Roman Numeralsroman_numerals.pypytest test_roman_numerals.py
    Linear Searchlinear_search.pypytest test_linear_search.py
  2. Make one test pass at a time. Then add your own tests for edge cases (both READMEs ask for this): add a def test_…(): and watch it fail before you handle it.
  3. Done = pytest prints only dots and N passed, and echo $? prints 0.

    If this breaks: assert None == 'I' = your function doesn't return yet. no tests ran = you're in the wrong folder (cd into the repo).

3 · Commit and push

  1. git add -A
git commit -m "Solve roman numerals with tests"
git push
    Or ask Claude (in the assignment folder): 
    Run git status and show me the list of files. Then suggest a commit message for my solution and wait for my approval. After I approve, commit and push to my fork.

    If this breaks: 403 / "Permission denied" on push = you cloned Code Platoon's repo, not your fork. git remote set-url origin https://github.com/YOUR-USERNAME/algo-roman-numeral-py.git

Homework Part II: Jest, then a calculator

In this order, top to bottom: (1) Fibonacci (Jest), (2) Linear Search (Jest), (3) Test my Calculator (pytest). Then 50 steps of your current FreeCodeCamp certification.

4 · The two Jest assignments

  1. Fork, clone your fork, cd into it. These repos already list Jest in package.json, so one command installs it: 
    npm install
npm test
    You'll see FAIL and a ● block per test: that's your red.
  2. Write fibonacci.js / linearSearch.js until npm test shows PASS. For Linear Search, add your own tests to the spec file.

    If this breaks: jest: command not found = run npm install first. Received: 0 or Received: undefined = the starter code is still answering: your function doesn't return your result yet. serializes to the same string = use toEqual for arrays.

  3. Commit and push, like step 3.

5 · Test my Calculator

  1. Fork and clone it, then follow its README: create calculator.py (the code is in the README) and test_calculator.py.
  2. Write tests for add, subtract, multiply and divide, the printed output with capsys, and the arguments with monkeypatch. Add a test that divide by zero raises: with pytest.raises(ValueError):
  3. Run pytest test_calculator.py until it's all green, then commit and push.
